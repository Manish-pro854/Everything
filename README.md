## 📌 About the Project

**Everything Mall** is a modern e-commerce web application that simulates an online shopping experience.
Users can browse products, explore different categories, and interact with a clean and responsive shopping interface.

This project demonstrates my skills in **React.js**, **component-based development**, and building scalable frontend applications using **Vite**.

---

## ✨ Features

* 🛍️ Product Listing System
* 📦 Product Categories
* 🔎 Easy Product Browsing
* 🧭 Smooth Page Navigation
* 📱 Responsive Design
* 🎨 Clean and Modern UI
* ⚡ Fast Performance using Vite

## 🚀 Getting Started (Run Locally)

Follow these steps to run the project on your computer.

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Manish-pro854/Everything.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd Everything
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Run Development Server

```bash
npm run dev
```

Open in browser:

```
http://localhost:5173
```
